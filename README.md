## 🎮 Project Description
The Hangman Game is a classic word-guessing game implemented in Python. The program randomly selects a word from a predefined list, and the player has to guess the letters to reveal the hidden word within 6 attempts.

## 🚀 Key Features
- **Random Word Selection:** The game selects a random word from a list of five predefined words.
- **Input Validation:** Ensures the user enters only a single, valid alphabetical character.
- **Game Logic:** Tracks incorrect guesses and limits the player to 6 attempts.
- **User Feedback:** Provides real-time feedback (e.g., "Good guess!", "Wrong guess!", "Already guessed that!").

## 🛠 Concepts Used
- `random` module
- `while` loops
- `if-elif-else` conditional statements
- `strings` and `lists`
- User Input/Output handling
